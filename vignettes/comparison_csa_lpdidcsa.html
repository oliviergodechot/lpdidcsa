Comparing lpdidcsa and did Packages for Difference-in-Differences Estimation

Olivier Godechot 2026-10-25

Introduction

This vignette shows how to use the lpdidcsa package for difference-in-differences (DiD) estimation and compares its results with those from the did package by Callaway and Sant’Anna. We focus on two estimation methods: inverse probability weighting (IPW) and regression adjustment. Additionally, we explore how lpdidcsa handles missing values, showcasing its pair rebalancing approach.

Setup

First, load the required packages and set the working directory.

library(data.table)

Data Preparation

We use the mpdta_r dataset from the lpdidcsa package for our analysis.

mpdta_w  <- lpdidcsa_data(mpdta_r, unit = "countyreal", time = "year",
                     dependent = "lemp", treat = "treat")

Comparison of Estimation Methods

Inverse Probability Weighting (IPW)

Using did Package

csa_ipw_det <- att_gt(
  yname = "lemp",
  tname = "year",
  idname = "countyreal",
  gname = "first.treat",
  base_period = "universal",
  control_group = c("notyettreated"),
  est_method = "ipw",
  bstrap = FALSE,
  cband = FALSE,
  xformla = ~lpop,
  data = mpdta_r
)
# summary(csa_ipw_det)
csa_ipw <- aggte(csa_ipw_det, type = "dynamic")
# summary(csa_ipw)
ggdid(csa_ipw)

Handling Missing Values

Creating a Dataset with Missing Values on the dependent variable

set.seed(444)
mpdta_r[, noise := runif(nrow(mpdta_r))]
mpdta_r[, drop := 1 - (noise > 0.1)]
mpdta_r[, lemp_mis := fifelse(drop==1,NA,lemp)]
mpdta_r[, rebal := (sum(!is.na(lemp_mis)) == 5) * 1, by = countyreal]
# mpdta_na[,.N, by = rebal]

Conclusion

This vignette demonstrates the use of the lpdidcsa package for DiD estimation and compares its results with the did package in R. The lpdidcsa package offers a robust approach to handling missing values through pair rebalancing, which can yield estimates closer to the “true” values without significant loss of power. (Pair balancing is also available in Callaway and Sant’Anna’s Stata package csdid. This option is not yet available in R. Here, it gives the same result as LPDiD).

For further details, refer to the package documentation and the original papers by Callaway and Sant’Anna, and the methodology behind lpdidcsa.
